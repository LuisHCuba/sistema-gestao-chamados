Detalhes do Projeto

Escopo do Projeto

O Sistema de Gestão de Chamados inclui:

  • Cadastro e gestão de usuários com níveis de acesso
  • Cadastro e controle de equipamentos
  • Abertura e acompanhamento de chamados
  • Sistema de SLAs com alertas de vencimento
  • Dashboard com indicadores e gráficos
  • Relatórios gerenciais
  • Histórico de manutenções
  • Integração com sistema de notificações

Tecnologias Utilizadas

Frontend

  • React.js
  • Tailwind CSS
  • JavaScript ES6+
  • PWA (Progressive Web App)

Backend

  • Node.js
  • Express
  • MongoDB
  • API RESTful

Infraestrutura

  • AWS ou Azure Cloud
  • Docker
  • CI/CD Pipeline
  • HTTPS SSL
